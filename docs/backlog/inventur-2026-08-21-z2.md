## S-1 · Rechte · `/planner/*` — 70 Routen nur `auth`, fünf Controller ohne Autorisierung

**beleg:** `routes/web.php:5314-5576` `Route::prefix('planner')->middleware(['web','auth'])`;
`grep -n "authorize\|Gate::\|Policy\|->can(" app/Http/Controllers/Planner/{PlannerPlan,PlannerItemState,PlannerMasterSet,PlannerAttendance,PlannerEmployeeApi}Controller.php`
→ kein Treffer; einziger `abort(403)` (`PlannerPlanController.php:2522`) prüft Datenkonsistenz,
keine Autorisierung; keine Konstruktor-Middleware. Controller angelegt 28.06. — vor der
Sicherheitsrunde, offenbar ausgespart.
**erklaerung:** jeder eingeloggte Mitarbeiter kann per Route-Parameter fremde Projekte/Pläne/
Items/Kommentare/Galerie lesen, ändern, **löschen**; Attendance-Check-in mit GPS-Standort.
**erledigt_wenn:** Schreib-/Lösch-Routen tragen `permission:` oder `authorize()` gegen eine
Team-/Zuständigkeits-Policy; Feature-Test „Fremder → 403" grün.
**loesungsvorschlag:** Policies nach vorhandenem Muster `DealMeasurementPolicy` (SEC-DM).
**aufwand:** L · **wirkung:** HOCH (LIVE, Datenschutz, destruktive Endpunkte)

## S-2 · Rechte · `GrundrissController` — Objekt-Geometrie lesen/schreiben ohne Ownership

**beleg:** `routes/web.php:5658-5664` (nur `auth` ab `:5621`); `editor()` (`:106-114`)
`HeizlastProjekt::find($projekt)` ohne Scope; `speichern()` (`:244-264`) `LeadAlternativeAdd::find`
+ neue Geometrie-Version ohne Check — **während der Nachbar `PlanUploadController::store:79` für
denselben Vorgang `hasPermission('Hausplaner','update')` verlangt.**
**erklaerung:** jeder Nutzer kann per URL fremde Gebäudegeometrie sehen und per POST eine neue
Grundriss-Version an ein fremdes Objekt hängen; Missbrauch bliebe unbemerkt.
**erledigt_wenn:** `editor()/index()/speichern()` prüfen dieselbe Berechtigung wie
`hausplaner.objekt.*`; Test „fremdes Objekt → 403" grün.
**loesungsvorschlag:** `abort_unless(...hasPermission('Hausplaner','update'), 403)` wie
`PlanUploadController:79`; Lesen gegen `Hausplaner,read` spiegeln. **aufwand:** M · **wirkung:** HOCH

## S-5 · Rechte · `ObjektakteController` (`/objekte/*`) — Gebäudeakte ohne Gate, Link nur versteckt

**beleg:** `routes/web.php:817-819` im Block `['web','auth']` ab `:793`;

(`~:440`) — Blade-Sichtbarkeit, keine Routensperre.
**erklaerung:** **umgekehrter Fall von S-4, und schwerer:** jeder eingeloggte Nutzer ohne

**erledigt_wenn:** Route-Gruppe oder Konstruktor erzwingt `permission:Customer,read`; Test „ohne
Customer-Recht → 403" grün.
**loesungsvorschlag:** `$this->middleware('permission:Customer,read')` im Konstruktor — Muster der
