Was der Rahmen heute Nacht dazugelernt hat

Neue Regelausgelöst durch
git commit -- <pfade> statt git add + git commit Dreimal an einem Abend nahm ein Commit fremde gestagte Arbeit mit. Die Regel „Index vor dem Commit lesen“ ließ ein Zeitfenster offen, das sie nicht benannte. Eine Barriere braucht keine Aufmerksamkeit im richtigen Moment.
Der Prüfstand muss nachfahrbar bleiben Scheibe 5 lag beim Evaluator, während der Baum auf Scheibe 6 weiterlief — seine Gates waren nicht mehr nachfahrbar. §13 regelt das Bauen, nicht das Prüfen. Das Werkzeug liegt seit B-01 im Repo: Worktrees je Rolle.
Während einer Sichtprobe bewegt niemand public/* Präzisierung einer zu weiten Sperre, die den Bauenden auf den Prüfenden warten ließ — zum zweiten Mal derselbe Fehler von mir.
Eine Mutation, die nicht greift, liefert ein falsches Grün Vom Evaluator: er prüft jede Gegenprobe erst auf Auffinden, bevor er sie als Beweis führt. Das ist die Gegenprobe zur Gegenprobe.
Geerbte Zusagen werden über die Eigenschaft gesucht, nicht über die Wörter style/inline Eine Suche, die das gesuchte Muster nicht enthält, findet zuverlässig nichts — und sieht dabei aus wie ein Beleg.
Maße kommen vom Behälter, nicht vom Fenster Zweimal dieselbe Fehlerklasse gemessen: innerWidth − 220 − 268 für die Breite, calc(100vh − 46px) für die Höhe. Solange das steht, ist die Insel weder einbettbar noch overlay-fähig.
