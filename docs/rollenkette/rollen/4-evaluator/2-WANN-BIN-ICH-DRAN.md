# WANN BIN ICH DRAN

| Lage | dran? |
|---|---|
| Ein Baubericht B liegt vor | **ja** |
| Ein A ist BEREIT, aber noch nicht gebaut | **ja, wenn ich einen Widerspruch sehe** → SPEC_BLOCKED vor dem Bau |
| Ich habe an diesem Auftrag gebaut | **nein — Rollentrennung, zwingend** |
| Ein Integrations-Merge steht auf `VEROEFFENTLICHT` und ich war an **keinem** Paket des Vorgangs beteiligt | **ja — Integrations-Abnahme** (Fassung 1.7, Nachtrag): Stand als Ganzes prüfen, Beteiligungs-Erklärung + Instanz-Kennung in den Bericht, Ball läuft **nur** über den Integrator |
| Integrations-Abnahme, aber ich war Generator/Evaluator/Release-Prüfer/Integrator des Vorgangs | **nein — nicht frisch, zwingend** |
