# WANN BIN ICH DRAN

| Lage | dran? |
|---|---|
| Kein Auftragsblatt A für ein offenes Werkzeug vorhanden | **ja** |
| Ein Votum C meldet Fehlerklasse **SPEC** | **ja** — der Schnitt trug nicht |
| Ein Baubericht B meldet SPEC_BLOCKED | **ja** |
| Yama benennt ein neues Werkzeug | **ja** |
| Ein Kriterium ist rot, Fehlerklasse CODE | nein — das ist der Generator |
| Ein Tor ist rot im Release | nein — das ist der Release-Prüfer |
